# Vault 2 branding provenance

The branded source is already applied to this repository's `web/` directory.
The retained `source.patch` records the original transformation against the
exact Infisical Agent Vault commit in `upstream.json`; do not apply it again
to this checkout. `LICENSE.upstream` preserves the reviewed upstream terms.

The theme uses warm graphite, champagne gold, a geometric V mark and the
Vault 2 name. The existing information architecture, bundled fonts, responsive
navigation/table behavior and upstream attribution are retained. External
resource links and the signed-in account menu are hidden at the owner's request.
Authentication, encryption and upstream engine source were not changed.

Build from `web/` using Bun as described in the root README. Existing Raven
startup and recovery are described in [operations](../../docs/operations.md).
Source preparation/publication does not replace the running app or alter its data.
